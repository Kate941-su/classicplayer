# 生成アートワーク（SPEC §4.10）

CMSL の音源には画像がないので、アプリ内で抽象的なアートワークを描く。iOS と Android は同じ規則で描く（描画の細部まで一致させる必要はないが、**色相・パターン・variant は一致させる**）。

## 入力と値

| 値 | 決め方 |
|---|---|
| `h` | 作曲家 ID（`composer.id`）の UTF-8 バイト列の **FNV-1a 32 ビット**ハッシュ（offset `0x811c9dc5`、prime `0x01000193`） |
| 色相 `hue` | `h mod 360`（度） |
| `variant` | `(h >> 16) & 0xff`。線の本数や中心の位置など、細部を決める |
| パターン | ジャンル ID で決める（下表）。未知のジャンルは「斜めの縞」 |

既知の値（テストで確かめる）: `fnv1a32("") = 0x811c9dc5`、`fnv1a32("a") = 0xe40c292c`、`fnv1a32("foobar") = 0xbf9cf968`

## パターン

| ジャンル ID | パターン |
|---|---|
| `symphony` | 同心円 |
| `orchestral` | 波線 |
| `concerto` | 角から広がる弧 |
| `piano` | 鍵盤の縞（白鍵の線と黒鍵） |
| `chamber` | 点の格子 |
| `vocal` | アーチの列 |
| `baroque` | ひし形の格子 |
| その他 | 斜めの縞 |

## 色
- 背景: 左上 `hsl(hue, 38%, 34%)` → 右下 `hsl(hue + 28, 38%, 18%)` の線形グラデーション
- 図形: `hsl(hue + 14, 38%, 78%)`、不透明度 約 60%
- 外部の画像や肖像写真は使わない

実装: Android `android/core/artwork/`
