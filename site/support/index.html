音源について

本アプリの音源は、CMSL クラシック名曲サウンドライブラリー（制作: ANDO TOWA）がフリー素材として公開している mp3 です（Creative Commons 表示 2.1 日本）。本アプリは音源を複製・再配布せず、CMSL のサーバーから直接再生します。

本アプリは CMSL の公式アプリではありません。アプリについてのお問い合わせを CMSL に送らないでください。

よくある質問

曲が再生できません

  • 再生にはインターネット接続が必要です（オフライン保存には対応していません）。
  • CMSL 側で音源が公開終了・移動された場合、その曲は再生できません。曲目は毎月更新され、再生できなくなった曲は一覧から外れます。お気に入りに登録していた場合は「この曲は現在利用できません」と表示されます。
  • 続けて 3 曲再生に失敗した場合は、再生を止めます。通信状況をご確認ください。

曲目はいつ更新されますか

毎月 1 日ごろに自動で更新されます。アプリの「情報」画面から手動で確認することもできます。

お気に入りは引き継げますか

お気に入りや履歴は端末の中だけに保存しているため、機種変更や再インストールでは引き継がれません（アカウント機能はありません）。

チップ（寄付）を買うと何が変わりますか

何も変わりません。すべての曲と機能は無料で使えます。チップは開発を応援していただくためのもので、購入すると「応援者」バッジが表示されます。バッジは端末の中だけの記録なので、再インストールすると消えます（購入の復元はありません）。

広告やデータの収集はありますか

ありません。詳しくはプライバシーポリシーをご覧ください。

お問い合わせ

GitHub Issues にお寄せください。ご報告の際は、アプリのバージョン、端末と OS のバージョン、曲名をお知らせいただけると助かります。Issues は公開されるため、個人情報は書かないでください。
